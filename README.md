# apis_scrips

Scripts Python para extraer los parches disponible por assets 

## Requisitos

- Python instalado
- uv para ejecutar los scripts
- API key válida de Vicarius
- El dashboard de tu organización (ej. `myorg` en https://myorg.vicarius.cloud)

## Configuración de credenciales

Crear un archivo `.env` en el directorio actual (NO subir este archivo al repositorio):

APIKEY=tu_token_de_vicarius
DASHBOARD=tuorg
